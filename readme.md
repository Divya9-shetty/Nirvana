# Nirvana

A simple web application for mental health and wellness built with HTML, CSS, and JavaScript.

## Features

* **Authentication:** Login, registration, password recovery, and user profile (`login.html`, `create.html`, `forgotpass.html`, `profile.html`).
* **Dashboard:** Central navigation hub (`dashboard.html`).
* **Wellness Chatbot:** Automated mental health chat support (`chatbot.html`, `chatbot.css`, `chatbot.js`).
* **Personal Diary:** Space for daily journaling (`diary.html`).
* **Self-Assessment:** Mental wellness questionnaire (`questionnaire.html`).
* **Phobia Guide:** Information about common phobias (`phobia.html`, `phobia.css`, `phobia.js`).
* **Info & Docs:** About page (`about.html`), contact page (`contact.html`), and full project report (`nirvanafinal.pdf`).

## How to Run

1. Download or clone the repository.
2. Open the `WT project` folder.
3. Double-click `login.html` or `dashboard.html` to open it in your browser.
